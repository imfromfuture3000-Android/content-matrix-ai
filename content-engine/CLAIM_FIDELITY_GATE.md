# Claim fidelity gate

Use this before any derivative leaves draft. Google's people-first content guidance treats unreviewed generative output as low effort, and a practical repurposing workflow assigns every derivative a source passage plus a named reviewer. This gate is that check. It does not publish, rank, or guarantee results.

## When it blocks

Do not record, schedule, or send a derivative if any row is still `blocked`.

- No source passage, URL, or owned transcript for the claim.
- The derivative adds a number, outcome, or testimonial the source does not support.
- Finance copy sounds like a personal recommendation. Educational context only.
- A tool claim names a feature, price, or limit that was not checked on the vendor page that day.
- Affiliate or sponsored relationship is not disclosed.

## Reviewer row

| Field | Fill before publish |
|---|---|
| Asset | Title and platform |
| Source passage | Quote or timestamp from the owned source |
| Derivative line | Exact spoken or posted sentence |
| Issue type | Fidelity, finance, tool fact, disclosure, or none |
| Reviewer | Name |
| Status | `blocked` or `approved` |

One source can feed many assets. Each asset still gets its own row.
